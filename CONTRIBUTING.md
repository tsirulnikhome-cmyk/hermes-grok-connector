# Contributing

This is a small, as-is project shared because others asked for the same thing. Issues and pull requests are welcome;
replies may be slow.

- Run the tests: `pip install -e ".[dev]" && pytest -q`.
- Keep it dependency-light and readable; no AI model in the memory path.
- Grok behavior reports are especially useful: what you said, what Grok did, and the connector's `TOOL` log lines
  (never paste your private address or key).
